  <files>apps/tui/src/session_manager.rs</files>
  <action>
    Create `apps/tui/src/session_manager.rs` with:

    **SessionEvent enum** for communicating from background reader tasks:
    ```rust
    pub enum SessionEvent {
        Output { session_id: String, line: String },
        Exited { session_id: String, exit_code: Option<i32> },
        Error { session_id: String, error: String },
    }
    ```

    **RunningSession struct** (internal):
    ```rust
    struct RunningSession {
        child: tokio::process::Child,
        stdin: tokio::process::ChildStdin,
        workspace_id: String,
        claude_session_id: Option<String>,
    }
    ```

    **SessionManager struct**:
    ```rust
    pub struct SessionManager {
        sessions: HashMap<String, RunningSession>,  // session_id -> running session
        event_tx: mpsc::UnboundedSender<SessionEvent>,
        event_rx: mpsc::UnboundedReceiver<SessionEvent>,
    }
    ```

    **Methods:**

    1. `new() -> Self` -- create mpsc channel pair, empty sessions map

    2. `start_session(&mut self, session_id: &str, workspace_dir: &str, resume_id: Option<&str>) -> Result<u32>`:
       - Build Command: `claude -p --input-format stream-json --output-format stream-json --cwd <workspace_dir>`
       - If resume_id is Some: add `--resume <id>`
       - Set `.stdin(Stdio::piped()).stdout(Stdio::piped()).stderr(Stdio::piped())`
       - Set `.env_remove("CLAUDECODE")` (pitfall 2 from research)
       - Set `.process_group(0)` (pitfall 6)
       - Set `.kill_on_drop(true)` (pitfall 1 safety net)
       - Spawn, take stdin/stdout/stderr handles
       - Spawn tokio task for stdout reader: BufReader::lines(), for each line strip ANSI escapes via `strip_ansi_escapes::strip_str()`, parse as JSON to extract text content and claude_session_id, send SessionEvent::Output via tx clone
       - Spawn tokio task for stderr reader: same pattern, send as Output events
       - Spawn tokio task to await child.wait(), send SessionEvent::Exited with exit code
       - Store RunningSession in sessions map
       - Return child PID

    3. `send_message(&mut self, session_id: &str, content: &str) -> Result<()>`:
       - Get mutable RunningSession
       - Write stream-json message: `{"type":"user","message":{"role":"user","content":"<content>"}}\n`
       - Flush stdin
       - Keep pitfall 4 in mind: do NOT drop stdin handle

    4. `stop_session(&mut self, session_id: &str) -> Result<()>`:
       - Get RunningSession, extract child PID
       - Send SIGTERM to process group: `nix::sys::signal::kill(Pid::from_raw(-(pid as i32)), Signal::SIGTERM)`
       - tokio::time::timeout(5s, child.wait())
       - On timeout: send SIGKILL to process group, then wait
       - Remove from sessions map

    5. `restart_session(&mut self, session_id: &str, workspace_dir: &str, claude_session_id: Option<&str>) -> Result<(String, u32)>`:
       - Stop session if running
       - Generate new session UUID
       - Start new session with resume_id = claude_session_id
       - Return (new_session_id, pid)

    6. `shutdown_all(&mut self) -> Result<()>`:
       - Collect all session IDs
       - For each: send SIGTERM to process group
       - tokio::time::timeout(5s total) waiting for all to exit
       - SIGKILL any remaining
       - Clear sessions map

    7. `poll_events(&mut self) -> Vec<SessionEvent>`:
       - Drain event_rx (try_recv in loop until Empty)
       - Return collected events
       - Caller (main.rs) calls this each tick to batch process output (pitfall 5: batch during 250ms tick)

    8. `get_claude_session_id(&self, session_id: &str) -> Option<String>`:
       - Return clone of claude_session_id from RunningSession

    9. `is_running(&self, session_id: &str) -> bool`

    **JSON output parsing helper** (private fn):
    - Parse each stdout line as serde_json::Value
    - Extract text from stream-json events: look for `result.content` or `content` fields
    - Extract `session_id` field if present, store as claude_session_id
    - If JSON parse fails, treat line as raw text (pitfall 3: graceful fallback)

    Add `mod session_manager;` to main.rs (just the module declaration, wiring is Plan 03).

    use ratatui::crossterm::event::{KeyCode, KeyModifiers, KeyEvent};
    use ratatui::widgets::{Block, Borders};
    use ratatui::style::Style;

    **Composer struct**:
    ```rust
    pub struct Composer {
        textarea: TextArea<'static>,
        active: bool,
    }
    ```

    **Methods:**

    1. `new() -> Self`:
       - Create TextArea::default()
       - Set block: `Block::default().title(" Send message ").borders(Borders::ALL)`
       - Set placeholder text: "Type a message... (Enter to send, Shift+Enter for newline)"
       - Set cursor_line_style to default (no highlight)
       - active = false

    2. `handle_key(&mut self, key: KeyEvent) -> Option<String>`:
       - Per user decision: Shift+Enter = newline, Enter = send
       - `KeyEvent { code: KeyCode::Enter, modifiers: KeyModifiers::SHIFT, .. }` -> forward to textarea.input(), return None
       - `KeyEvent { code: KeyCode::Enter, .. }` -> extract all lines, join with "\n", trim. If empty return None. Clear textarea (create new TextArea::default() with same config). Return Some(text).
       - All other keys -> forward to textarea.input(), return None

    3. `clear(&mut self)`:
       - Reset textarea to fresh default with same block/style config
       - Helper to reuse the textarea setup logic

    4. `set_active(&mut self, active: bool)`:
       - self.active = active
       - Update block style (dim border when inactive, normal when active)

    5. `is_active(&self) -> bool`

    6. `widget(&self) -> &TextArea<'static>`:
       - Return reference for rendering. The TextArea implements Widget.

    7. `height_hint(&self) -> u16`:
       - Return 3 (minimum height for composer -- 1 line + borders)
       - Could grow based on content lines, but start simple
