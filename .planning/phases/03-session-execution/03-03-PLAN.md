    **2. Update TreeNode::Workspace to show session status:**
    In `rebuild_tree()` and the rendering in `ui()`, look up session status for each workspace:
    - Find session via `state.find_session_by_workspace(ws.id)`
    - Append status icon after workspace name: " ▶" (Running), " ■" (Stopped), " ✗" (Failed/Exited)
    - Keep active/archived dot separate from session status icon

    **3. Update right pane rendering in `ui()`:**
    Split right pane into two areas when a session exists for the selected workspace:
    - Top: scrolling output (Paragraph widget with visible_lines from ScrollbackBuffer)
    - Bottom: composer (pinned, 3 lines height via Composer::height_hint)
    - Horizontal border between them
    - Use Layout with vertical split: `[Constraint::Min(1), Constraint::Length(composer_height)]`

    When no session for selected workspace:
    - Show existing workspace details (current behavior)
    - Add hint line: "Press 'r' to start a session"

    - Get visible_lines from ScrollbackBuffer for the active workspace
    - Wrap in Paragraph widget with soft-wrap (Wrap { trim: false })
    - When buffer empty and session running: show "Session started. Waiting for output..."
    - When scrolled up (not at bottom): show " ↓ N new lines " indicator at bottom-right of output area
    - Auto-scroll: if is_at_bottom(), new lines auto-show

    **User messages inline:** When composer sends a message, push "> {message}" lines to scrollback before sending to session_manager.

    **4. Update key handling in `run()`:**

    Add new key handlers (respect composer_focused state):

    When composer_focused:
    - Ctrl+C: clear composer input (composer.clear())
    - Enter/Shift+Enter/other: delegate to composer.handle_key()
    - If composer.handle_key() returns Some(text): send message to session_manager, push "> {text}" to scrollback, add separator line
    - Esc: unfocus composer (set composer_focused = false)

    When NOT composer_focused:
    - Existing: q, j/k/arrows, Enter (expand/select)
    - New 'r': on workspace node -- create session via state.create_session(), call session_manager.start_session(), set active_session_id, create scrollback buffer, focus composer
    - New 'R': on workspace with stopped session -- restart via session_manager.restart_session(), update state session, clear scrollback, focus composer
    - Ctrl+C: if session running for selected workspace -> stop it; if no session -> quit app (same as 'q')
    - Page Up / Page Down (or Ctrl+U/Ctrl+D): scroll output buffer up/down
    - Tab: toggle composer focus when session active

    When selecting a different workspace (cursor moves):
    - Update active_session_id to that workspace's session
    - Show that workspace's scrollback (or details if no session)
    - Instant switching per user decision

  <name>Task 2: CLI session subcommands (start/stop/list/clear)</name>
  <files>apps/cli/src/main.rs</files>
  <action>
    Add Session subcommand to CLI following existing pattern (Repo/Workspace subcommands).

    **1. Add to Commands enum:**
    ```rust
    /// Manage sessions
    Session {
        #[command(subcommand)]
        action: SessionAction,
    },
    ```

    **2. Define SessionAction:**
    ```rust
    #[derive(Subcommand)]
    enum SessionAction {
        /// Start a Claude session in a workspace
        Start {
            /// Workspace name
            workspace: String,
        },
        /// Stop a running session
        Stop {
            /// Workspace name
            workspace: String,
        },
        /// List all sessions
        List,
        /// Clear session metadata and log file
        Clear {
            /// Workspace name
            workspace: String,
        },
    }
    ```

    **3. Implement handlers:**

    `Start`:
    - Load state, find workspace by name
    - Check no running session for workspace
    - Create session in state (state.create_session())
    - Spawn claude process with std::process::Command (not tokio -- CLI doesn't need async event loop)
    - Set process_group(0), env_remove("CLAUDECODE"), spawn()
    - Store PID in session, save state
    - Print: "Started session for workspace: {name}" and "Session ID: {id}"

    `Stop`:
    - Load state, find running session for workspace
    - Get PID from session
    - Send SIGTERM to process group (nix::sys::signal::kill)
    - Wait briefly (std::thread::sleep 1s), check if still running, SIGKILL if needed
    - Update session status to Stopped, save state
    - Print: "Stopped session for workspace: {name}"

    `List`:
    - Load state, list all sessions
    - Print table: SESSION_ID, WORKSPACE, STATUS, PID, CREATED
    - Match workspace_id to workspace name for display

    `Clear`:
    - Load state, find session for workspace
    - Remove session from state.sessions vec
    - Delete log file if exists
    - Save state
    - Print: "Cleared session for workspace: {name}"

    **4. Add dependencies to CLI Cargo.toml** (if not already done in Plan 01):
    - nix (for signal sending in stop command)
    - Add `nix.workspace = true` to apps/cli/Cargo.toml
