    - Test: push_line beyond capacity drops oldest line (FIFO via pop_front)
    - Test: scroll_up increases offset, is_at_bottom returns false
    - Test: scroll_down decreases offset, reaches 0 = at bottom
    - Test: push_line while scrolled up increments new_lines_since_scroll
    - Test: push_line while at bottom does NOT increment new_lines_since_scroll
    - Test: reset_scroll sets offset to 0 and clears new_lines_since_scroll
    - Test: visible_lines returns correct slice for given viewport height
    - Test: visible_lines with scroll offset returns older lines
    - Test: capacity of 50000 works without panic
  </behavior>
  <action>
    Create `apps/tui/src/scrollback.rs` with:

    ```rust
    pub struct ScrollbackBuffer {
        lines: VecDeque<String>,
        capacity: usize,
        scroll_offset: usize,       // 0 = bottom (auto-scroll mode)
        new_lines_since_scroll: usize,
    }
    ```

    Methods:
    - `new(capacity: usize) -> Self` -- VecDeque::with_capacity(capacity.min(10_000)) for initial alloc, store full capacity for enforcement
    - `push_line(line: String)` -- pop_front if at capacity, push_back, increment new_lines_since_scroll if scroll_offset > 0
    - `push_lines(lines: impl IntoIterator<Item = String>)` -- batch push for efficiency (research pitfall 5: batch during tick)
    - `len() -> usize`
    - `is_empty() -> bool`
    - `is_at_bottom() -> bool` -- scroll_offset == 0
    - `scroll_up(n: usize)` -- increase offset, clamp to max (len - 1)
    - `scroll_down(n: usize)` -- decrease offset, clamp to 0
    - `reset_scroll()` -- set offset to 0, clear new_lines_since_scroll
    - `new_lines_count() -> usize` -- return new_lines_since_scroll
    - `visible_lines(&self, height: usize) -> Vec<&str>` -- return up to `height` lines ending at (len - scroll_offset). Use iter().skip(start).take(height) pattern since VecDeque slicing requires make_contiguous.
    - `clear()` -- clear all lines and reset scroll state

    Add `mod scrollback;` at the top of main.rs for now (keeping it simple as TUI only has main.rs currently).
