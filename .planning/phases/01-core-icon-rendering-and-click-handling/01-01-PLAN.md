Replace `truncate_path` with unicode-safe version that uses `UnicodeWidthStr::width()` for length check and `char_indices().rev()` + `UnicodeWidthChar::width()` for finding the correct byte boundary to keep the tail of the path (matches existing behavior of showing "...{tail}").
