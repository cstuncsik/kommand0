  <action>
Modify the `TreeNode::Workspace` arm inside `render_tree` (currently lines 91-121) to:

1. **Before the `.map()` closure**, compute `pane_inner_width`:
   ```rust
   let pane_inner_width = area.width.saturating_sub(2) as usize; // subtract left+right borders
   ```
   This must be available inside the closure. Either compute it before the `.map()` or capture `area` in the closure (area is already available since it's a parameter to `render_tree`).

2. **Inside the `TreeNode::Workspace` arm**, replace the current span-building + `session_status_icon` call with fill-span layout:

   a. Look up the session for this workspace: `let session = app.state.find_session_by_workspace(&ws.id);`
   b. Call `workspace_icon_cluster(session, &ws.id)` to get the `IconCluster`.
   c. Calculate layout widths:
      - `prefix` = `"  \u{251C}\u{2500} "` (already exists, 5 display columns)
      - `prefix_width` = `UnicodeWidthStr::width(prefix)` (should be 5)
      - `dot_width` = 1 (the dot char)
      - `space_after_dot` = 1 (the space in `format!(" {}", ws.name)`)
      - `fixed_width` = `prefix_width + dot_width + space_after_dot` (= 7)
      - `name_max_width` = `pane_inner_width.saturating_sub(fixed_width + icons.total_width as usize)`
      - Truncate name: `let display_name = truncate_to_width(&ws.name, name_max_width);`
      - `name_display_width` = `UnicodeWidthStr::width(display_name.as_str())`
      - `fill_width` = `pane_inner_width.saturating_sub(fixed_width + name_display_width + icons.total_width as usize)`

   d. Build spans:
      ```rust
      let mut spans = vec![
          Span::styled(prefix, style),
          Span::styled(dot, Style::default().fg(dot_color)),
          Span::styled(format!(" {}", display_name), style),
          Span::raw(" ".repeat(fill_width)),
      ];
      spans.extend(icons.spans.clone());
      ```

   e. Remove the old `session_status_icon` call (lines 117-119 currently).

3. **After `render_stateful_widget`**, register hit regions for each workspace's icons. This requires a second pass because we need `list_state.offset()` which is only valid after rendering.

   Currently `render_tree` builds items in a `.map().collect()` and renders them. To register hit regions, collect the icon data alongside the items:

   a. Change the `.map()` closure to also return icon hit region data for workspace rows. Use a separate vec to collect `(usize, IconCluster)` tuples -- tree_item index and its icons.

   b. After `frame.render_stateful_widget(list, area, &mut list_state)`:
      ```rust
      let scroll_offset = list_state.offset();
      for (item_idx, icons) in &workspace_icons {
          if let Some(row_in_viewport) = item_idx.checked_sub(scroll_offset) {
              let y = area.y + 1 + row_in_viewport as u16; // +1 for border
              if y < area.y + area.height - 1 { // within viewport (before bottom border)
                  let mut icon_x = area.x + 1 + pane_inner_width as u16 - icons.total_width;
                  for (action, icon_width) in &icons.hit_regions {
                      app.hit_regions.push(buttons::HitRegion {
                          area: Rect::new(icon_x, y, *icon_width, 1),
                          action: action.clone(),
                      });
                      icon_x += icon_width;
                  }
              }
          }
      }
      ```

   Important details:
   - The `app.hit_regions.clear()` already happens at the top of `ui()`, so no extra clearing needed.
   - The closure currently borrows `app` immutably for `session_status_icon`. The new code needs `app.state.find_session_by_workspace()` which is also an immutable borrow -- this is fine.
   - `pane_inner_width` must be `as u16` for the Rect math in hit region registration.
   - The hit region x-coordinate uses `area.x + 1` (left border) + offset to reach the icon position.

4. **Handle the borrow checker**: The `.map()` closure borrows `app` (for `session_status_icon` currently, and for `find_session_by_workspace` in the new code). The hit region registration also needs `&mut app.hit_regions`. Solution: collect all icon data during the map phase (immutable borrow of app), then after the stateful widget render, push hit regions (mutable borrow of app.hit_regions). This is the two-phase approach.

NOTE on `pane_inner_width`: Be careful with the "inner width" -- it's `area.width - 2` (for left and right borders). The List widget with Borders::ALL already accounts for this in the content area, so our fill-span calculation should match.

```rust
}
```

Replace with a dispatch that handles both old (detail-pane) and new (tree-icon) variants:

```rust
if let Some(action) = app.pending_button_action.take() {
    match action {
        // Detail-pane buttons (use selected workspace)
        buttons::HitAction::StartSession | buttons::HitAction::ResumeSession => {
            if let Some(ws) = app.selected_workspace().cloned() {
                // ... existing start/resume logic (unchanged)
            }
        }
        buttons::HitAction::StopSession => {
            if let Some(ws) = app.selected_workspace().cloned() {
                // ... existing stop logic (unchanged)
            }
        }
        // Tree-icon buttons (use carried workspace_id)
        buttons::HitAction::StartSessionFor { workspace_id } => {
            if let Some(ws) = app.state.workspaces.iter().find(|w| w.id == workspace_id).cloned() {
                // Same logic as StartSession but using `ws` from the carried ID
                // Create session, start it, set up scrollback
                if let Ok(new_session) = app.state.create_session(&ws.id) {
                    let session_id = new_session.id.clone();
                    match app.session_manager.start_session(&session_id, &ws.working_dir, None) {
                        Ok(pid) => {
                            if let Some(s) = app.state.find_session_mut(&session_id) {
                                s.pid = Some(pid);
                            }
                            let _ = app.state.save();
                            app.scrollbacks
                                .entry(ws.id.clone())
                                .or_insert_with(|| ScrollbackBuffer::new(50_000))
                                .reset_scroll();
                            // Do NOT change focus or selection -- user clicked on a non-selected row
                        }
                        Err(_) => {
                            let _ = app.state.update_session_status(&new_session.id, SessionStatus::Failed);
                        }
                    }
                }
            }
        }
        buttons::HitAction::StopSessionFor { workspace_id } => {
            if let Some(session_id) = app.state.find_session_by_workspace(&workspace_id)
                .filter(|s| s.status == SessionStatus::Running)
                .map(|s| s.id.clone())
            {
                let _ = app.session_manager.stop_session(&session_id).await;
                let _ = app.state.update_session_status(&session_id, SessionStatus::Stopped);
                if let Some(buf) = app.scrollbacks.get_mut(&workspace_id) {
                    buf.push_line("--- Session stopped ---".to_string());
                }
                // Do NOT change focus
            }
        }
        buttons::HitAction::ResumeSessionFor { workspace_id } => {
            if let Some(ws) = app.state.workspaces.iter().find(|w| w.id == workspace_id).cloned() {
                let claude_sid = app.state.find_session_by_workspace(&ws.id)
                    .and_then(|s| s.claude_session_id.clone());
                // Stop old session
                if let Some(old_id) = app.state.find_session_by_workspace(&ws.id).map(|s| s.id.clone()) {
                    let _ = app.state.update_session_status(&old_id, SessionStatus::Stopped);
                }
                if let Ok(new_session) = app.state.create_session(&ws.id) {
                    let session_id = new_session.id.clone();
                    match app.session_manager.start_session(&session_id, &ws.working_dir, claude_sid.as_deref()) {
                        Ok(pid) => {
                            if let Some(s) = app.state.find_session_mut(&session_id) {
                                s.pid = Some(pid);
                                s.claude_session_id = claude_sid;
                            }
                            let _ = app.state.save();
                            app.scrollbacks
                                .entry(ws.id.clone())
                                .or_insert_with(|| ScrollbackBuffer::new(50_000))
                                .reset_scroll();
                        }
                        Err(_) => {
                            let _ = app.state.update_session_status(&new_session.id, SessionStatus::Failed);
                        }
                    }
                }
            }
        }
        buttons::HitAction::RetrySessionFor { workspace_id } => {
            // Retry = start fresh (same as StartSessionFor)
            if let Some(ws) = app.state.workspaces.iter().find(|w| w.id == workspace_id).cloned() {
                if let Ok(new_session) = app.state.create_session(&ws.id) {
                    let session_id = new_session.id.clone();
                    match app.session_manager.start_session(&session_id, &ws.working_dir, None) {
                        Ok(pid) => {
                            if let Some(s) = app.state.find_session_mut(&session_id) {
                                s.pid = Some(pid);
                            }
                            let _ = app.state.save();
                            app.scrollbacks
                                .entry(ws.id.clone())
                                .or_insert_with(|| ScrollbackBuffer::new(50_000))
                                .reset_scroll();
                        }
                        Err(_) => {
                            let _ = app.state.update_session_status(&new_session.id, SessionStatus::Failed);
                        }
                    }
                }
            }
        }
    }
}
```

Key differences from the detail-pane dispatch:
- The `*For` variants look up the workspace by `workspace_id` from `app.state.workspaces`, NOT from `app.selected_workspace()`.
- The `*For` variants do NOT change focus or selection (the user clicked an icon on a row they might not have selected).
- `RetrySessionFor` starts a fresh session (no resume ID).

Also important: The `stop_session` call is `.await` -- this is inside an async block so it works. Verify the existing pattern matches.
