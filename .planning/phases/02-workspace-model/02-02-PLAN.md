<task type="auto">
  <name>Task 1: Tree view with expand/collapse, navigation, and context-sensitive right pane</name>
  <files>apps/tui/src/main.rs</files>
  <action>
    Refactor the TUI `App` struct, `ui()` function, and key handling to replace the flat repo list with an expandable tree view and make the right pane context-sensitive.

    **Part A: Data model**

    1. Add imports: `use kommand0_core::{Workspace, workspace::format_timestamp};` and `use std::collections::HashSet;`

    2. Define TreeNode enum:
       ```rust
       enum TreeNode {
           Repo { id: String, name: String, workspace_count: usize },
           Workspace { ws: Workspace, repo_name: String },
           Hint { text: String },
       }
       ```

    3. Refactor App struct:
       - Remove `selected: ListState` (replacing with manual index tracking)
       - Add `workspaces: Vec<Workspace>` (loaded from AppState)
       - Add `expanded: HashSet<String>` (repo IDs that are expanded, starts empty)
       - Add `tree_items: Vec<TreeNode>` (flattened visible tree, rebuilt on expand/collapse)
       - Add `selected_index: usize` (index into tree_items)
       - Keep `repos`, `output`, `status`

    4. Add `rebuild_tree(&mut self)` method on App:
       - Clear tree_items
       - For each repo: push `TreeNode::Repo` with workspace_count (count matching workspaces)
       - If repo is expanded: push its workspaces as `TreeNode::Workspace` items (with repo_name from repo.name.clone())
       - If repo is expanded and has no workspaces: push `TreeNode::Hint { text: "(no workspaces)".into() }`
       - If repo is expanded and all workspaces are archived: push the workspaces, then append `TreeNode::Hint { text: "(all archived)".into() }`
       - Call this in `App::new()` and after every expand/collapse toggle

    5. Refactor `App::new()`: Accept `(repos: Vec<RepoEntry>, workspaces: Vec<Workspace>)`. Initialize expanded as empty HashSet. Call rebuild_tree(). Set selected_index to 0 if tree_items not empty.

    **Part B: Navigation**

    6. Refactor navigation:
       - `move_up()`: decrement selected_index (wrap to end). Skip Hint nodes (they are not selectable).
       - `move_down()`: increment selected_index (wrap to 0). Skip Hint nodes.
       - New `toggle_expand()`: called on Enter when a Repo node is selected. Toggle repo ID in expanded set. Call rebuild_tree(). If collapsing, adjust selected_index to stay on the repo node. Clamp selected_index to tree_items.len() - 1.

    7. Update key handling in `run()`:
       - Enter on Repo node: call toggle_expand()
       - Enter on Workspace node: run git status for its repo (look up repo path from repos vec using ws.repo_id)
       - Enter on Hint node: do nothing
       - j/k/Up/Down: call move_down/move_up as before
       - q: quit

    8. Update `run()` function: Load `state.repos` and `state.workspaces` together. Pass both to `App::new()`.

    **Part C: Left pane rendering**

    9. Refactor `ui()` left pane:
       - If tree_items is empty: show "No repos tracked. Run: kmd repo add <path>" as dimmed hint text in left pane
       - Build `Vec<ListItem>` from tree_items:
         - `TreeNode::Repo`: triangle indicator + repo name. Use "\u{25B6} " (right triangle) if collapsed, "\u{25BC} " (down triangle) if expanded. Style: yellow bold if selected.
         - `TreeNode::Workspace`: "  \u{251C}\u{2500} " connector prefix + status dot + " " + workspace name. Active dot: "\u{25CF}" in Color::Green. Archived dot: "\u{25CB}" in Color::DarkGray. Text style: yellow bold if selected, DarkGray if archived and not selected, default otherwise.
         - `TreeNode::Hint`: "     " prefix + dimmed italic text
       - Use `List` widget with `ListState` set to selected_index for highlight
       - Block title: " Repos "

    **Part D: Context-sensitive right pane**

    10. Refactor `ui()` right pane to be context-sensitive based on selected TreeNode:
        - **No selection / empty tree**: Paragraph with "Select a workspace to see details" in dimmed text. Block title: " Details "
        - **Repo selected**: Key-value layout showing:
          - Name: {repo.name}
          - Path: {repo.path} (truncate with ellipsis if wider than pane - 4)
          - Workspaces: {count} active, {total} total
          Block title: " Repo: {repo.name} "
        - **Workspace selected**: Key-value layout showing:
          - Name: {ws.name}
          - Repo: {repo_name}
          - Dir: {ws.working_dir} (truncate with ellipsis if wider than pane - 4)
          - Status: "active" (green) or "archived" (dark gray)
          - Created: {format_timestamp(ws.created_at)}
          Block title: " Workspace: {ws.name} "
        - **Hint selected** (shouldn't happen due to skip logic, but handle): same as no selection

        Key-value rendering: Each line is a `Line` with two Spans -- label in bold cyan, value in default style. Use `Span::styled("Name: ", Style::default().fg(Color::Cyan).add_modifier(Modifier::BOLD))` for labels.

    11. Add path truncation helper function:
        ```rust
        fn truncate_path(path: &str, max_width: usize) -> String {
            if path.len() <= max_width { return path.to_string(); }
            if max_width < 4 { return "...".to_string(); }
            let keep = max_width - 3;
            format!("...{}", &path[path.len() - keep..])
        }
        ```

    Auto-select first repo on launch but do NOT auto-expand (per CONTEXT.md).
