    3. Create `apps/tui/src/wrap_map.rs` with:

    **VisualRow struct:**
    ```rust
    #[derive(Debug, Clone, PartialEq)]
    pub struct VisualRow {
        pub logical_line: usize,
        pub start_byte: usize,
        pub end_byte: usize,
        pub width: u16,
    }
    ```

    **WrapMap struct with methods:**
    - `build(lines: &[&str], pane_width: usize) -> Self` -- Replicates ratatui's WordWrapper with `trim: false`. Iterate each line's grapheme clusters (via `UnicodeSegmentation::graphemes(true)`). Track `current_row_width`, `pending_word` (Vec of (grapheme, display_width, byte_offset)), and `pending_whitespace` (same). On whitespace: if pending_word would overflow, emit current row and start new row with the word. On word char after whitespace: flush whitespace + word to current row. When a single word exceeds pane_width, break it at the width boundary. Empty lines produce one empty VisualRow.
    - `screen_to_logical(&self, x: u16, y: u16, scroll_from_top: usize) -> Option<(usize, usize)>` -- Convert visual row index (y + scroll_from_top) to logical position. Walk grapheme clusters in that row's byte range to find the char_offset at display column x.
    - `logical_to_screen(&self, line: usize, char_offset: usize, scroll_from_top: usize) -> Option<(u16, u16)>` -- Find the VisualRow containing that logical position, compute x from grapheme widths, y from row index minus scroll_from_top.
    - `total_visual_rows(&self) -> usize` -- `self.rows.len()`
    - `extract_text(&self, lines: &[&str], start: (usize, usize), end: (usize, usize)) -> String` -- Extract text between two logical (line, char_offset) positions. char_offset is a grapheme index, not byte offset. Iterate graphemes to find byte boundaries, slice, join multi-line with "\n".

    **Critical implementation details:**
    - Use `unicode_segmentation::UnicodeSegmentation::graphemes(s, true)` for grapheme iteration
    - Use `unicode_width::UnicodeWidthStr::width(grapheme)` for display width of each grapheme
    - Store byte offsets (start_byte, end_byte) for efficient string slicing
    - Match ratatui WordWrapper behavior: whitespace-to-word transition triggers flush, word overflow triggers line break, single-word overflow triggers character-level break
    - With trim=false: do NOT strip leading whitespace from continuation lines

    4. Write tests FIRST (RED), then implement to make them pass (GREEN). Follow RED-GREEN-REFACTOR cycle.
