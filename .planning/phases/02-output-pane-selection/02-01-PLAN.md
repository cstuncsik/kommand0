  <action>
1. Implement `overlay_style_on_line()` as described in the research (02-RESEARCH.md code example). This is the core span-splitting function that takes a Line, a display-column range (start_col, end_col), and a Style, then splits spans at grapheme boundaries to apply the style overlay. Use `unicode_segmentation::UnicodeSegmentation::graphemes(true)` and `unicode_width::UnicodeWidthStr::width()` for correct splitting.

2. Implement `apply_selection_highlight()`:
   ```rust
   pub(crate) fn apply_selection_highlight(
       lines: &mut Vec<Line<'static>>,
       selection: &SelectionState,
       scroll_from_top: usize,
       inner_height: usize,
       raw_lines: &[&str],
       wrap_map: &WrapMap,
   )
   ```
   - Get ordered_range from SelectionState
   - For each visible styled Line (scroll_from_top..scroll_from_top+inner_height):
     - Determine which display-column range of this Line is selected by mapping logical selection positions through WrapMap
     - Call overlay_style_on_line with Style::default().bg(Color::Cyan).fg(Color::Black)
   - Note: The styled Lines from build_output_lines correspond 1:1 with the logical raw_lines (one styled Line per raw line, before ratatui's Paragraph wraps them). The WrapMap handles the visual row mapping. For selection overlay, operate on the pre-wrap styled Lines using logical line indices and character offsets.

3. Implement `apply_cursor_highlight()`:
   ```rust
   pub(crate) fn apply_cursor_highlight(
       lines: &mut Vec<Line<'static>>,
       cursor_line: usize,
       cursor_char: usize,
       blink_on: bool,
       focused: bool,
   )
   ```
   - If !focused: apply dim style (Style::default().add_modifier(Modifier::DIM)) to cursor character
   - If focused && blink_on: apply Style::default().bg(Color::White).fg(Color::Black) to cursor character
   - If focused && !blink_on: no style override (cursor invisible during blink-off phase)
   - If cursor_char is past end of line content: append a Span with a single space character styled as cursor
   - Use overlay_style_on_line internally for the single-character range

4. Wire into render pipeline: In both `render_right_pane()` (line ~373) and `render_zoomed()` (line ~945+), after `build_output_lines()` returns styled_lines and before `render_output_content()`:
   - Get the workspace's SelectionState from app.selections
   - Build a WrapMap from raw_lines and inner_width
   - Call apply_selection_highlight if selection has_range
   - Call apply_cursor_highlight if selection is Cursor or Range (cursor is always visible when state != None)
   - Pass `app.cursor_blink_on` and `app.focus == Focus::Output` for blink/focus params

5. The `styled_lines` variable must become `mut` in render_right_pane and render_zoomed for the highlight functions to modify it.
