**Helper functions** (add as methods on App or free functions in main.rs):

1. `ensure_cursor_visible(buf, wrap_map, cursor_line, cursor_char, inner_height, lines)` -- adjusts scroll_offset so cursor's visual row is within viewport. Uses compute_scroll_from_top for the conversion. Uses buf.set_scroll_offset() to set position directly.

2. `move_cursor_vertical(app, ws_id, direction: i32)` -- moves cursor up/down by visual rows:
   - Build WrapMap from scrollback all_lines + pane inner_width (use app.pane_areas.output.width - 2)
   - Get current cursor position from app.selections[ws_id]
   - Convert to screen coords via logical_to_screen
   - Move y by direction, keep x at desired_col (from app.cursor_desired_col[ws_id])
   - Convert back via screen_to_logical
   - Update SelectionState::Cursor with new position
   - Call ensure_cursor_visible
   - Suppress auto-scroll (add ws_id to auto_scroll_suppressed)

3. `move_cursor_horizontal(app, ws_id, direction: i32)` -- moves cursor left/right by one character:
   - Get current position from selections
   - If moving right: increment char_offset. If past end of line, wrap to start of next line
   - If moving left: decrement char_offset. If at start of line (0), wrap to end of previous line
   - Update desired_col to new screen x position
   - Call ensure_cursor_visible

4. `word_boundary_next(line: &str, char_offset: usize) -> usize` and `word_boundary_prev(line: &str, char_offset: usize) -> usize` -- word boundary detection using grapheme iteration. Skip current word chars then skip whitespace (or vice versa for prev). Use the algorithm from 02-RESEARCH.md.

5. `init_cursor_if_needed(app, ws_id)` -- if selections[ws_id] is None, initialize to bottom-left of visible content: last logical line, char_offset 0. This is called on first arrow key press in output pane.

**Key dispatch structure** (replaces lines 797-861):

```rust
Focus::Output => {
    let ws_id = app.selected_workspace().map(|ws| ws.id.clone());
    if let Some(ws_id) = ws_id {
        let shift = key.modifiers.contains(KeyModifiers::SHIFT);
        let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);

        match (key.code, ctrl, shift) {
            // --- Cursor movement (no modifiers) ---
            (KeyCode::Up, false, false) => { init_cursor_if_needed; move_cursor_vertical(app, ws_id, -1); }
            (KeyCode::Down, false, false) => { init_cursor_if_needed; move_cursor_vertical(app, ws_id, 1); }
            (KeyCode::Left, false, false) => { init_cursor_if_needed; move_cursor_horizontal(app, ws_id, -1); clear_selection_keep_cursor(); }
            (KeyCode::Right, false, false) => { init_cursor_if_needed; move_cursor_horizontal(app, ws_id, 1); clear_selection_keep_cursor(); }

            // --- Word jump (Ctrl+arrow) ---
            (KeyCode::Left, true, false) => { init_cursor_if_needed; move_cursor_word_left(app, ws_id); }
            (KeyCode::Right, true, false) => { init_cursor_if_needed; move_cursor_word_right(app, ws_id); }

            // --- Selection extend (Shift+arrow) ---
            (KeyCode::Up, false, true) => { init_cursor_if_needed; extend_selection_vertical(app, ws_id, -1); }
            (KeyCode::Down, false, true) => { init_cursor_if_needed; extend_selection_vertical(app, ws_id, 1); }
            (KeyCode::Left, false, true) => { init_cursor_if_needed; extend_selection_horizontal(app, ws_id, -1); }
            (KeyCode::Right, false, true) => { init_cursor_if_needed; extend_selection_horizontal(app, ws_id, 1); }

            // --- Word-extend selection (Shift+Ctrl+arrow) ---
            (KeyCode::Left, true, true) => { init_cursor_if_needed; extend_selection_word_left(app, ws_id); }
            (KeyCode::Right, true, true) => { init_cursor_if_needed; extend_selection_word_right(app, ws_id); }

            // --- Document navigation ---
            (KeyCode::Home, _, false) => { move_cursor_to_document_start(app, ws_id); }
            (KeyCode::End, _, false) => { move_cursor_to_document_end(app, ws_id); }
            (KeyCode::Home, _, true) => { extend_selection_to_document_start(app, ws_id); }  // Shift+Home
            (KeyCode::End, _, true) => { extend_selection_to_document_end(app, ws_id); }      // Shift+End

            // --- Page navigation ---
            (KeyCode::PageUp, false, false) => { move_cursor_page_up(app, ws_id); }
            (KeyCode::PageDown, false, false) => { move_cursor_page_down(app, ws_id); }

            // --- Select all ---
            (KeyCode::Char('a'), true, _) => { select_all(app, ws_id); }  // Ctrl+A

            // --- Scroll-only shortcuts (j/k remain for scrolling without cursor) ---
            (KeyCode::Char('k'), false, false) => { scroll_and_clear_selection(app, ws_id, true); }
            (KeyCode::Char('j'), false, false) => { scroll_and_clear_selection(app, ws_id, false); }

            // --- Legacy shortcuts remapped ---
            (KeyCode::Char('g'), false, false) => { move_cursor_to_document_start(app, ws_id); }
            (KeyCode::Char('G'), false, false) => { move_cursor_to_document_end(app, ws_id); }

            // --- Existing ---
            (KeyCode::Char('z'), false, false) => { app.zoomed = !app.zoomed; }
            (KeyCode::Char('i'), false, false) => { /* enter composer -- existing logic */ }

            _ => {}
        }
    }
}
```

**Selection extension logic:**
- `extend_selection_*` functions: If current state is Cursor { line, char }, transition to Range { anchor: (line, char), cursor: new_pos }. If already Range, update cursor field only (anchor stays).
- On plain arrow movement (no Shift), if currently in Range, collapse to Cursor at the cursor end of the range.

**Auto-scroll suppression:**
- When cursor is placed (any arrow key, Home/End, PageUp/PageDown), add ws_id to auto_scroll_suppressed.
- When user scrolls to bottom (j scrolls past end, or explicitly), remove from auto_scroll_suppressed.
- Find where new output triggers reset_scroll() (likely in the streaming event handler) and gate it: `if !app.auto_scroll_suppressed.contains(&ws_id) { buf.reset_scroll(); }`.

**PageUp/PageDown (VS Code style):**
- Calculate page size from app.last_output_height - 2.
- Move cursor's visual row by page size (up or down), keeping screen-relative position.
- Adjust scroll_offset by the same page amount.
- Clamp cursor to document bounds.

**Desired column memory:**
- On horizontal movement (Left/Right/word jump): update cursor_desired_col to current screen x.
- On vertical movement (Up/Down): use cursor_desired_col as target x, do NOT update it.
- This preserves column position when moving through short lines.
